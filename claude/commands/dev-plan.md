# Plan Implementation

## コンテキスト
以下の内容を確認してください。
- 指定された Notion チケットの内容
- チケットに含まれる "Figma" プロパティのリンク先のデザイン
- チケット本文に含まれる Figma リンク先のデザイン

### ルール
- 対象が省略された場合は要求する
- 実装と対応する Figma デザインが見つからない場合は要求する
- 情報の取得には GitHub, Notion, Figma の MCP を使用する

## タスク
チケットに対応する実装を計画してください。

## ルール
- ultrathink
- 現在の実装状況を確認する
- レビューで指摘されることが予想される内容は予め考慮する
- 必要に応じて Web 上のドキュメントを参照し正確な情報に基づいて判断する
- ドキュメントの参照には Context7 を使用する
- 各実装領域の `CLAUDE.md` を遵守する
- 実装完了後に計画外の対応箇所をリストアップすることを計画に含める

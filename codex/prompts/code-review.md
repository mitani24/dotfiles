# Code Review

## コンテキスト
以下の内容を確認してください。
- 指定された PR の内容
- PR に含まれる Notion のチケットの内容
- チケットに含まれる "Figma" プロパティのリンク先のデザイン
- チケット本文に含まれる Figma リンク先のデザイン
- チケットに含まれる "親タスク" プロパティのリンク先の内容
- 親タスクのチケットの "Figma" プロパティのリンク先のデザイン
- 親タスクのチケット本文に含まれる Figma リンク先のデザイン

### ルール
- 対象が省略された場合は `!gh pr view --json url` で取得する
- 実装と対応する Figma デザインが見つからない場合は要求する
- 情報の取得には GitHub, Notion, Figma の MCP を使用する
- ブランチのチェックアウトはしない

## タスク
PR をレビューし、レポートを作成してください。

## レビュー観点
次の点に焦点を当てて評価します。
- UX: 変更はユーザーにとって直感的で快適なものになっているか
- ビジュアルの一貫性: デザインに準拠しているか
- ユーザビリティとアクセシビリティ: UI が直感的でアクセシビリティ標準に準拠しているか
- インタラクションフロー: ユーザーフローがシームレスか
- コード品質と保守性: コードは読みやすく保守しやすい構造になっているか
- パフォーマンスとスケーラビリティ: 変更は大規模な環境でも効率的に機能するか
- ベストプラクティス: コーディング標準やスタイルガイドからの逸脱がないか
- テストカバレッジ: 十分なテストがあるか
- 潜在的なバグとエッジケース: すべてのエッジケースが考慮されているか
- リグレッションリスク: 変更によって既存の機能が損なわれなていないか
- 脆弱性: 変更によってセキュリティ上の脆弱性が生じないか
- データの取扱: 機密データが適切に保護されているか
- コンプライアンス: セキュリティまたはプライバシー標準へ準拠しているか

### 領域ごとのガイドライン
ガイドラインは極めて重要なレビュー基準です。
- 共通
  - @docs/domain-glossary.md
- apps/bff, apps/bff-setup
  - @docs/bff-guidelines.md
- apps/frontend, apps/frontend-setup
  - @docs/frontend-pages.md
  - @docs/frontend-code-readability.md
  - @docs/frontend-coding-style.md
  - @docs/frontend-testing-style.md
  - @docs/frontend-guidelines.md

## ルール
- **誤った評価をしないために深く考える**
- **最高のコード品質となるよう多角的かつ厳格に評価しすべてのレビューコメントを出し切る**
- 必要に応じて Web 上のドキュメントを参照し正確な情報に基づいて判断する
- ドキュメントの参照には Context7 を使用する
- 引用元のリンクを明記する
- ガイドライン違反の場合は該当するガイドラインの箇所を示す

## レポート方法
- 全体評価 (承認/却下) `<result>` を示す
- 全体に対するレビューを Overall Review コメントとして示す
- 個々のファイルに対するレビューを File Review コメントとして示す
- 各レビューコメントには通し番号 `<number>`、タグ `<tag>`、および簡潔なタイトル <title> を示す
- ファイルごとのレビューコメントにはファイルパス `<file-path>` を示す
- 改善提案を示す
- 以下のテンプレートに従う

```md
# PR #0000 Review Report: <result>

## Overall Review

### <number>. <tag> <title>

<comment>

## File Review

### <number>. <tag> <title>

<comment>

<file-path>
```

### result

- [✅ APPROVED]: 承認
- [💩 REJECTED]: 却下

### タグ

- [🚨 MUST]: この対応がされていないと Approve できない
- [💭 IMO]: この対応がされていなくても Approve できる
- [✏️ NITS]: 細かい指摘
- [❓ ASK]: 確認
- [🔮 NEXT]: 今後の改善点
- [🌟 GOOD]: 良い点
- [💡 SUGGESTION]: 提案
